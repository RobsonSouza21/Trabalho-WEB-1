Este projeto foi desenvolvido como parte da disciplina Web I, no primeiro semestre da faculdade.
O objetivo é aplicar os conhecimentos iniciais de desenvolvimento para a construção de páginas web utilizando:

HTML5

CSS3

Estruturação semântica

Organização em múltiplas páginas

Hospedagem de site estático

📌 Sobre o Projeto

O site contém diversas telas, simulando um ambiente completo para prática de:

Formulários (cadastro de pessoa física, estudantil, postal)

Organização de conteúdo visual (carrosséis)

Exibição de gráficos (simulados em HTML/CSS)

Exibição de tabelas dinâmicas

Página de localização com mapa incorporado (Google Maps)

Layout responsivo

Navegação entre abas no topo das páginas

🎯 Objetivos do Trabalho

Estruturar páginas HTML com conteúdo organizado

Separar estilo em arquivos CSS externos

Criar uma identidade visual consistente entre as telas

Trabalhar com o conceito de container, cards e navegação

Implementar interatividade visual sem JavaScript (carrosséis em CSS puro)

Publicar o projeto em ambiente online (hospedagem gratuita)

🧩 Tecnologias Utilizadas

HTML5 — estrutura

CSS3 — estilização

Google Fonts / System UI Fonts

Google Maps Embed
